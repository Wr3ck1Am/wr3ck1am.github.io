RobotAgentBench

Co-project leader · Co-first authorarXiv · Oct 2026

Towards Open-world Robot Autonomy

Co-led a benchmark for household robot autonomy, from explicit manipulation instructions to open-ended assistance. My work spans evaluation design, task construction, model adaptation, and experiments, assessing task discovery, context reasoning, manipulation, failure recovery, and robustness.

Project website ↗arXiv ↗Code ↗
Paper details

RobotAgentBench studies the gap between executing predefined tasks and acting autonomously on high-level user needs. Task-level tests assess five capabilities, while open-ended scenarios examine how agents combine them. Experiments compare standalone VLA/WAM policies with planning–execution–verification agents and study hybrid execution and recursive self-improvement. Published as Towards Open-world Robot Autonomy (arXiv:2610.34649, October 2026).

CRIS-0

Co-first authorReleased Oct 2026

A Causal Robotic Intelligence System

A causal agent and world model working together for long-horizon robot autonomy. I owned the agent-side planner, executor, unified tool interface, and execution policies, integrating the Causal World Action Model policy on AgiBot G1.

Causal task state · Skill orchestration · Recovery

Research blog ↗
System details

CRIS-0 connects a causal agent with a Causal World Action Model to bring reasoning and physical action into one system. The agent reasons about how actions change the world, while the learned policy carries out physical interactions on AgiBot G1. Public household demonstrations explore long-horizon tidying, tablecloth replacement, and skill transfer to new objects.

03 / ROBOT LEARNING↗ The next action has a history.CAMP · FRANKA PANDA

CAMP

Co-second author · UC San Diego ARCLabSubmitted to CoRL Workshop & TRA

Behavioral memory for partially observable manipulation

Learning from what a robot has already done. CAMP uses action-history reconstruction to learn compact behavioral memory for Diffusion Policy. My contributions focus on Memory-T-Bench / Memory-Manip-Bench demonstration and evaluation infrastructure, plus baseline experiments.

64.3% mean success across seven 3D tasks +23.4 pp

Project website ↗arXiv ↗
Paper details

Remember what you did?: Learning Behavioral Memories for Partially Observable Object Manipulation

Co-second author, advised by Prof. Michael Yip. Submitted to CoRL Workshop and TRA. Built Memory-T-Bench / Memory-Manip-Bench demonstration and evaluation infrastructure and ran ACT, Diffusion Policy, π0.5, and MemoryVLA baselines. Paper results include 64.3% mean success across seven 3D tasks (+23.4 percentage points over the best baseline). In four Franka Panda tasks, three reached 7/10 versus 0/10 for all baselines; Probe-Insert reached 11/15.

04 / WORLD MODELING↗

Video2World

Author · Aether AIarXiv · Oct 2026

Benchmarking coding agents for interactive world modeling from embodied videos

A benchmark for coding agents that turn robot and human demonstration videos into executable simulations. Agents reconstruct the scene and robot behavior, then refine them through execution feedback. Evaluation separates geometric fidelity, dynamic fidelity, and functional correctness.
